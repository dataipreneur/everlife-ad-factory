# Which reference to use when (MOTS-c)

> **MOTS-c (adapted 2026-10-30 from BPC-157):** active adults 30–55, men and women; energy and endurance, never physique; no weight, fat or body-composition words or images; no disease words. Template wording cleaned 2026-11-02; if any BPC-157, gym or recovery wording remains, it describes the template product, not MOTS-c: `direction.md` and `product-bible.md` win.


The reference library is the SHARED one, `core/references/static-refs/` (13 folders; overview in `OVERVIEW.jpg`; `13_Premium_DTC/`
holds the Hims/Ro codes). It teaches **layout, type scale, product staging and mood**, never words or scenes. Pick ONE pin per slot,
look at it, and borrow only its structure. No MOTS-c winners yet.

**People:** read `direction.md` first.

Rules of thumb:
- Dan's rule: **one vial per ad**, one promise, one plain line that explains it; nothing about weight or bodies.
- Carla's rule: if the pin's mood is "diet product", take only its type scale and leave the scene.
- Never reuse the same pin for two slots in one batch; never the same framework twice unless the batch is bigger than 8.
