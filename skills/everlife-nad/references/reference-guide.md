# Which reference to use when (NAD+)

The reference library is the SHARED one, `core/references/static-refs/` (13 folders; overview in `OVERVIEW.jpg`; `13_Premium_DTC/`
holds the Hims/Ro codes). It teaches **layout, type scale, product staging and mood**, never words or scenes. Pick ONE pin per slot,
look at it, and borrow only its structure. NAD+ winner files are not on hand yet (`winners/winners.md`).

| NAD+ angle | Best frameworks | In the folder, pick the pin that is… | Avoid in that folder |
|---|---|---|---|
| **Clear head** — "Less Fog. More Focus.", "Brain Fog, Who?" | F2 · F8 Question · F11 | 08: huge one-line question pins; 11: single-object metaphor pins | neon "energy drink" pins |
| **Energy that lasts** — "Fuels All-Day Energy + Focus", "Wake Up Feeling Recharged Again" | F1 · F3 Phone UI · F12 | 03: loading/battery UI pins; 12: bright morning still lifes | caffeine-hype pins |
| **The choice** — "Choose Your Form" | F4 · F6 Offer | 04: two-product comparison layouts with lots of air; 06: clean percent-off pins | anything showing an injection being given |
| **Healthy aging** — "More Life in Your Years.", "Promotes Healthy Aging" | F14 · F12 | 13: Hims/Ro codes; calm, premium | age-reversal / before-after pins |

**People:** read `direction.md` first.

Rules of thumb:
- Priya's rule: **one promise**, one plain line, the form (or the choice) clear; no hype words.
- Tom's rule: if the pin's mood is "clinic" or "anti-aging", take only its type scale and leave the scene.
- Never reuse the same pin for two slots in one batch; never the same framework twice unless the batch is bigger than 8.
