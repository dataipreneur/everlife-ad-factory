Rules of thumb:
- Dave's rule: **one product, one tablet, one promise**, one plain line that explains the promise; the combo named together.
- Maya's rule: if the pin's mood is "bedroom", take only its type scale and leave the scene.
- Never reuse the same pin for two slots in one batch; never the same framework twice unless the batch is bigger than 8.
