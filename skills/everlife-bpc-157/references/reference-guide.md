# Which reference to use when (BPC-157)

The reference library is the SHARED one, `core/references/static-refs/` (13 folders; overview in `OVERVIEW.jpg`; `13_Premium_DTC/`
holds the Hims/Ro codes). It teaches **layout, type scale, product staging and mood**, never words or scenes. Pick ONE pin per slot,
look at it, and borrow only its structure. Our own approved BPC-157 statics are in Canva (`winners/winners.md`): open them first.

**Vial staging:** `vial-refs/` (48 vial-hero ads, `OVERVIEW.jpg` + README with what to borrow and the traps). Pick one code per vial-hero slot.
**Men's ads:** read `mens-direction.md` first (cast, scene bank, type, the Sermorelin male winners M2/M3/M8 as staging references).

Rules of thumb:
- Marcus's rule: **one form per ad**, one promise, one plain line that explains the promise; nothing that sounds like a cure.
- Dana's rule: if the pin's mood is "gym bro", take only its type scale and leave the scene.
- Never reuse the same pin for two slots in one batch; never the same framework twice unless the batch is bigger than 8.
